# ADR-002 — App name: MyClash

**Date:** 2025-01-01
**Status:** Accepted

## Context

The platform needed a name that is:

- Short, memorable, and easy to type
- Evocative of HEMA competition without being exclusionary to non-HEMA combat sports
- Available as a `.fr` domain (French community focus)
- Not already trademarked in the sports-software space

## Decision

**MyClash** — combining the personal "My" prefix (user ownership, personalization) with "Clash" (combat, competition, encounter).

Domain registered: `myclash.fr`.

## Consequences

- **Easy:** Brand identity is clear and consistent across all surfaces (app, marketing, social).
- **Hard:** "Clash" has broad cultural connotations (Clash of Clans, etc.) — not a problem in practice given the niche audience.
- **Committed to:** All package names use `@myclash/` scope; all subdomains follow `*.myclash.fr`.

## Alternatives considered

- **hemaManager** — Too narrow; excludes other historical martial arts.
- **TournoisAMHE** — Too French-only; limits international adoption.
- **SwordTrack** — Available but bland; doesn't convey the competitive/event management angle.
