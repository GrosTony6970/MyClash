# docs/prototype/

The original HTML prototype that established MyClash's design language (Cinzel + Inter typography, red/blue HEMA palette, gold accents, shield motifs).

This is **canonical reference material** for the public PWA's visual design (T-601, T-602, T-604). The agent reads this when implementing the design tokens package and themed components.

Drop the prototype HTML files here. The repo's `.gitignore` does not exclude this directory — these files are committed and reviewed.
