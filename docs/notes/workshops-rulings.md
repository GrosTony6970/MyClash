# Workshop rulings — MyClash

## Context

The operator asked "what is missing for a Workshop user or organiser?" on 2026-11-09. The answer
became the Workshops track: safety fixes first (group 1), then the organiser's and the attendee's
gaps (groups 2 and 3), one slice at a time.

Each question was asked with a short story, and the operator picked one answer. This file keeps
every ruling of that track, 512 to 581, with its story and its answer. Code comments and tests cite
these numbers ("ruling 545"): look them up here. Rulings 1 to 511 belong to other tracks; most are
in `quick-wins-2026-10-08.md`.

The plans and the session handoffs live outside the repo, in the operator's plans folder
(`workshops-slice-2-1-plan.md`, `workshops-ruling-526-plan.md`, `workshops-slice-2-2-plan.md`,
`workshops-slice-2-3-plan.md`, `workshops-slice-2-4-plan.md`, `workshops-handoff.md`).

A new Workshop ruling gets its row here in the next docs commit. "Not picked" names the other
answers the operator was offered, when the record kept them.
