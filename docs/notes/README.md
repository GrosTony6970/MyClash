# docs/notes/

Free-form thematic notes that don't fit elsewhere. Examples:

- `glossary.md` — HEMA terminology in EN/FR (referenced by translation work).
- `<topic>.md` — design explorations, references, research summaries.

Kept separate from `memory/notes/` (which is the AI agent's working memory) and `docs/decisions/` (which captures specific decisions as ADRs).
