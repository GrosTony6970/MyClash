# docs/notes/

Free-form thematic notes that don't fit elsewhere:

- `glossary.md` — HEMA terminology in EN/FR (referenced by translation work).
- `quick-wins-2026-10-08.md` — the quality-of-life rows the operator picked on 2026-10-08, and the
  register of the operator's numbered rulings since then. Code comments and commit messages cite a
  ruling by its number ("ruling 492"); this file is where the number resolves.
- `workshops-rulings.md` — the rulings of the Workshops work, kept apart.
- `<topic>.md` — design explorations, references, research summaries.

Kept separate from `docs/decisions/`, which captures specific decisions as ADRs. Agent working
memory lives outside this repo entirely — there is no `memory/` directory here.
