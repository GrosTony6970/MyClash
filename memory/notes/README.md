# memory/notes/

Thematic deep-dive notes spawned by the AI agent when an entry in `MEMORY.md` grows too large to live there.

The agent is responsible for maintaining these. Each note should be focused on one theme (e.g. `tf-v1-edge-cases.md`, `pool-generation-tradeoffs.md`, `realtime-debounce-strategy.md`) and linked from `MEMORY.md` under the "Themes" section.

Rules (per `AGENTS.md` persistent-memory protocol):

- One topic per file.
- Update or delete when information becomes obsolete.
- Never duplicate content from `MEMORY.md` or other thematic notes — link instead.
