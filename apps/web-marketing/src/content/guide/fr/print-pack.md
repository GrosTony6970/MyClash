**Ce que vous allez apprendre :** ce que contient le dossier papier, et pourquoi l'imprimer avant
l'événement.

## Pourquoi du papier

Les tablettes de score continuent de marcher sans réseau (voir
[Fiche du marqueur](/guide/scorekeeper-sheet)). Le dossier papier sert le jour où l'application
elle-même est injoignable : vous faites les combats sur papier et saisissez les résultats ensuite.

**Imprimez-le avant l'événement.** La page lit tout depuis le serveur : il lui faut le réseau.
Gardez les feuilles à chaque lice.

## L'imprimer

1. Dans la vue d'ensemble de l'événement, ouvrez la carte **Dossier papier**.
2. Si l'événement a plusieurs tournois, choisissez-en un sous **Tournoi**, ou **Tous les tournois, en
   une seule impression**.
3. Sous **Que faut-il imprimer ?**, cochez les feuilles voulues.
4. Cliquez sur **Imprimer**. Le dossier s'ouvre dans une nouvelle fenêtre, et la boîte d'impression
   s'ouvre seule. Si rien ne s'ouvre, autorisez les fenêtres surgissantes pour le site.

Chaque membre de votre organisation peut imprimer le dossier.

## Les feuilles

Toutes les feuilles sont en A4, une par page. Chaque en-tête nomme l'événement, le tournoi, le
règlement et l'heure d'impression, à l'heure de l'événement.

| Feuille                | Cochée au départ | Ce qu'elle contient                                                                                                                                 |
| ---------------------- | ---------------- | --------------------------------------------------------------------------------------------------------------------------------------------------- |
| **Feuilles de poule**  | Oui              | Une page par poule : les combattants, puis chaque combat avec le score, les coups doubles, les pénalités et le vainqueur, et une ligne de signature |
| **Feuille de tableau** | Oui              | Tous les combats du tableau, tour par tour, avec une case de score pour chaque côté et sa lice                                                      |
| **Feuilles de piste**  | Oui              | Une page par lice : ses combats dans l'ordre horaire, avec les arbitres. Les combats sans lice ont leur propre page                                 |
| **Feuilles de match**  | Non              | Une page par combat : 20 lignes d'échanges numérotées, les pénalités et les notes, le vainqueur et une ligne de signature                           |

## Ce qu'il laisse de côté

- **Les combats suisses :** le dossier ne contient que les poules et les tableaux.
- **Un tournoi sans poules ni tableau :** il n'y a rien à imprimer. Avec **Tous les tournois**, ce
  tournoi est laissé de côté.
- **Deux combattants du même nom** dans une poule apparaissent sur une seule ligne de la liste des
  combattants de la poule.
